# Toxic-Comment-Filtering
A multi-label toxic comment classifier built for gaming platform live chat — detects categories like spam, insult, profanity, and hate speech, assigns a severity score (0–5), and recommends moderation actions (allow / warn / mute / auto-ban) using the Jigsaw Toxic Comment dataset. Tech: Python · scikit-learn · TF-IDF · Pandas · NLP
